# Index

## Fichiers permanents

- `PERSONA.md` — qui je suis (nom, tempérament, style, journal d'évolution)
- `CREED.md` — ce que je tiens (valeurs, ordres permanents, frontières, domaine)

- `MEMORY.md` — ce que je sais (connaissance longue, curée)
