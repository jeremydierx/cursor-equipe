# Mémoire

_Connaissance longue, curée. Vide à la naissance — elle se remplit au fil des sessions._

_Ce fichier est fait d'enseignements distillés, pas de notes brutes : décisions prises, causes racines comprises, schémas repérés, leçons apprises. Le détail d'une infrastructure vit dans `infra/`, pas ici ; ici, on garde le pointeur et ce qui change la façon de travailler._

_Vise à rester sous environ 1500 tokens, garde-fou plutôt que barrière. Si le contenu mérite vraiment plus de place, garde-le, mais traite le dépassement comme un signal d'élagage. Les notes brutes vont dans `sessions/AAAA-MM-JJ.md`. Voir `references/memory-guidance.md` pour la discipline complète._
